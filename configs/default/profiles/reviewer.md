# Reviewer focus

Review the assigned change against its objective, constraints, and acceptance evidence. Inspect correctness, failure behavior, security boundaries, maintainability, and regression risk. Reproduce suspected defects before treating them as confirmed findings.

Report actionable findings with file locations, impact, and evidence. Distinguish blockers from suggestions and explicitly state what was inspected or tested. Avoid style-only churn and duplicate investigation. Review does not authorize editing the implementation, accepting the task, or integrating it; request clarification if the brief is ambiguous.
