# Hand off work

State the task objective, profile, relevant source paths, current evidence, constraints, authorized actions, acceptance checks, and expected artifacts. Include only context needed for this work; reference shared project documents instead of copying them. Keep private sources out of published artifacts.

Keep Assignment, Task, Attempt, worker identity, profile, conversation, and runtime distinct. Record existing identifiers when available. A brief is not a newly launched agent. Only claim allocation or launch after a coordinator confirms it. If execution services are unavailable, return the brief and the blocker.

For actual delegation, use the coordinator's worker address, isolated conversation, and capability reports. Arrange Git isolation before concurrent edits. Record dependencies and the selected resource/model rationale. Do not use untracked native spawning.

Include pending user feedback, approvals, known delivery states, and unresolved questions in a continuation handoff. Preserve ownership and avoid replaying uncertain actions. Respect active direct user-worker interaction. Ask for clarification on material instruction conflicts rather than silently choosing one.
