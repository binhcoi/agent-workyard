# Plan work

Read the relevant project instructions and sources. Determine whether the user requested planning, investigation, or implementation. Preserve that authorization boundary throughout the plan.

Identify the intended outcome, established constraints, and stopping condition. Investigate uncertainties only when they affect a decision. Ask material questions with a recommendation; otherwise state the assumption and proceed with planning.

Produce executable work items with inputs, dependencies, acceptance checks, and significant risks. Choose steps, roles, and review according to the task rather than imposing a stage pipeline. Explain decisions separately from optional suggestions.

Consider available runtime/model capabilities, capacity, and known limits when proposing delegated work. Do not invent quota numbers or create extra agents just to administer an Assignment. End with a concrete plan. Begin implementation only when the user has authorized it.
